% --- Abstract ---
\begin{abstract}
\noindent
This master technical specification documents the complete architecture, signal processing algorithms, computer vision pipelines, 3D geometric reconstruction models, vehicle dynamic validation frameworks, and user-facing analytics dashboards developed for the EPICS DSN3099 project: \textit{Rural Road Condition, Connectivity Gap \& Safety Mapper}.

By unifying decoupled low-cost monocular RGB dashcam feeds with smartphone/vehicle accelerometer streams, the system achieves sub-centimeter pothole depth characterization validated through physical quarter-car dynamic simulation. The Version 2.5.0 release introduces five major advances beyond prior documentation: \textbf{(1)} a fully transparent Sensor Reading Pipeline section in the Streamlit dashboard displaying live computed values at each of five stages; \textbf{(2)} a Corridor Health Score (CHS) weighting detected potholes by severity tier; \textbf{(3)} an instantaneous bituminous repair cost estimate using Indian PWD standard rates; \textbf{(4)} a four-level Repair Urgency classifier (Immediate / Within 30 Days / Within 90 Days / Monitor); and \textbf{(5)} a simplified upload-only interface focused on field deployment usability.

The system processes raw dashcam images and produces verified 3D cavity geometry, physics-validated shock predictions, economic repair estimates, corridor health indices, and actionable GIS connectivity maps---all running on commodity consumer hardware with zero specialized survey equipment.
\end{abstract}
